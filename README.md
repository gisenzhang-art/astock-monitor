# A股智监 - 智能数据监测与量化模拟交易系统

## 项目概述

A股智监是一套完整的A股市场数据监测与量化模拟交易系统，涵盖行情监测、板块资金分析、个股排名、龙虎榜、模拟交易、消息情报、自动复盘学习和专属知识库8大模块。

- **PC端**：深色主题金融看板，8个功能页面，数据密集型布局
- **移动端**：同花顺手机端风格，5个页面（首页/行情/交易/资讯/我的）
- **数据层**：真实A股行情数据 + 模拟资金流向数据
- **交易规则**：10万初始资金，严格T+1，量化策略驱动

## 系统架构

```
前端展示层: PC端深色看板(8页) | 移动端同花顺风格(5页)
API服务层: 行情 | 板块资金 | 个股排名 | 龙虎榜 | 模拟交易 | 消息栏 | 知识库 | 复盘学习
数据存储层: 指数表 | 个股表 | 板块表 | 资金流表 | 持仓表 | 交易记录 | 消息表 | 知识库 | 复盘记录
```

## 8大模块

1. **行情板块实时监测** - 四大指数卡片 + 板块资金热力图 + 净流入/流出排名 + 9:30/11:30/15:00三时点汇报
2. **板块资金曲线可视化** - 全板块资金曲线 + 科技AI上中下游细分赛道 + 涨跌四维解析
3. **个股资金排名Top30** - 净流入/净流出各30只 + 支撑位/主力动向/消息分析
4. **龙虎榜分析** - 资金可视化 + 机构席位明细 + 明日上板3股多维分析
5. **模拟盘(10万/T+1)** - PC端持股页 + 移动端同花顺风格 + 买卖策略标记
6. **消息栏(6分类)** - 行情/板块/个股/龙虎榜/模拟盘/科技股专属消息
7. **自动化复盘学习** - 交易复盘 + 亏钱标记 + 策略迭代 + 买卖信号
8. **专属知识库** - 分类存储 + 搜索检索 + 个股档案 + 策略库

## 数据说明

- 真实数据：大盘指数(含7日历史)、AI/半导体头部个股，来源同花顺金融数据库，日期2026-09-24
- 模拟数据：板块资金流向、龙虎榜数据，已在界面标注
